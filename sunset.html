SUNSET CODES

The Scalable Unstructured Node-SET codes provide a flexible, adaptive high-order meshless framework for direct numerical simulations. They are primarily tailored towards premixed combustion problems, but have been adapted for isothermal flows of viscoelastic fluids.

The codes can be found here

Please note that these are academic codes under continuous development. For guidance on the numerical methods, please see the code documentation and related papers [1][2][3].

For advice or support using the code, please get in touch at jack (dot) king (at) manchester (dot) ac (dot) uk

CODE FEATURES

  • Fully compressible reacting multispecies Navier-Stokes equations
  • Spatial discretisation: LABFM in-plane, central FD in third dimension. 4th to 10th order (default 8th), dropping to 4th order on non-periodic boundaries.
  • Time integration: 3rd order explicit Runge-Kutta, with 2nd order embedded error estimation for dynamic time step control
  • Boundary conditions - characteristic based: adiabatic & isothermal walls, non-reflecting and hard inflows, non-reflecting outflows
  • Acceleration: MPI+OpenMP. Tested up to 32768 cores (85% parallel efficiency)
  • Transport models: a) mixture averaged, b) constant Le and Pr
  • Reaction mechanisms: arbitrary. Currently included: 1 step Arrhenius, 21 step H2-air, 25 step CH4-air, inert air
In addition, there is a branch of the code dedicated to viscoelastic flows, which solves the isothermally compressible Navier-Stokes equations along with an evolution equation for the conformation tensor (log-conformation and Cholesky-log decomposition options available).
